# 在线分块 PCT 地图

## 坐标、存储与读取

`online_layer_map` 和探索控制在一个进程。输入为 map 坐标系的
`/slam/global_cloud_registered` 的逐帧注册命中点。G/C 只来自真实命中点，不要求额外配对雷达位姿。
可通过 `auxiliary_cloud_topic` 融合第二路已注册到 map 的点云。
世界原点固定，XY 格中心为 `origin + index * resolution`，
归属使用 `floor(value/resolution + 0.5)`。XY 分辨率与高度切片间隔分别配置。

地图使用 `(slice_id, block_x, block_y) -> 固定大小 NumPy 结构数组`。
默认块大小 32×32，新增区域添加新块，已有块不扩容、不重新居中、不搬迁。
切片采用固定的有符号高度编号；最低参考切片低于点云，最高参考切片高于点云，
运行期间只扩展编号范围，不做切片简化。按计算依赖为邻近实测列补齐局部切片表示，
避免斜坡跨切片出现人为断缝；远处高楼不会要求全图补齐其全部切片。

局部切片需求以分块布尔掩码保留，包括暂时尚无真实观测的 XY 位置。
新列后来收到点云时会继承该位置此前已有的切片需求，再从本列共享真实表面查询 G/C，
避免微小正负高度扰动跨过切片边界后，新列缺少邻列正在使用的表示并产生假未知膨胀。
原生高度范围与继承范围分别记录：只有本列真实证据涉及的原生切片会向周围发出需求，
继承到的切片不再向外递推，因此计算范围仍限制在原有局部依赖邻域。
需求掩码不含高度，不创建未观测列的地面；后续代价、机体空间、连通性与前沿仍在同批提交更新。

每个 XY 列维护一份按高度排序的共享表面记录：表面编号、平均高度、点数、
真实高度范围和成熟状态。层格保存 g_surface_id / c_surface_id 及对应 G/C 缓存。
同一表面的多个切片缓存来自同一条记录，G 严格相同；一个点只给表面计数一次。

`pct_max_surface_records` 限制全图共享表面数量；`pct_max_map_cells` 按已分配块限制内存。
不再使用固定高度桶、z_resolution、三维均值/散布矩阵/协方差、极值尾部样本或动态时间批次。
未成熟记录仅临时保留最多 num-1 个标量高度和输入序号，供两个候选归并时正确取最早的 num 个样本；
成熟后立即释放。它不保存历史 XYZ 点云，也不生成规划快照。
正常融合直接更新唯一工作图；接近容量上限时，仅暂存本帧触及列的少量记录，以便整帧拒绝超限输入。

生产路径不生成稠密规划快照。原生 PCT A* 新增 `init_accessor`，
直接借用在线图查询格子，仅为搜索访问过的节点分配工作区。
原有稠密接口仍供离线 PCT 使用。`export_dense()` 只用于明确的离线验证，
不参与在线构图、选点、可视化和规划。

## 每格信息

基础信息：`G`、`C`、`passage_cost`。
扩展代价：`relief_cost`、`terrain_cost`、`inflated_terrain_cost`。
`relief_cost` 是一个变量，在平缓和台阶两个分支赋值。
另有共享表面编号、成熟状态、局部几何缓存及代价传播参考值。

对切片高度 h，在同列有序平均高度中查找：G 引用不高于 h 的最高表面，
C 引用高于 h 的最低表面。二者绝不引用同一编号。二分查找跳过其余无关表面；
所有层格共享同一列的有序表面证据，各自保存 G/C 和成熟状态。
若地面噪声跨过切片边界，先被同一高度组接收；不会再次按正负高度拆成两个表面。
切片仍保持固定原点、固定间隔，不做切片简化。

净空按该切片的 `C - G` 计算。有 G 无 C 时，`passage_cost=0`，仍计算地形和机体空间条件。
缺 G 的格子为未知。已有 G 的格子立即计算净空代价，缺少邻格高度时地形代价仍为未评估（-1）。
高度差只读取有效 G，不要求整个邻域都有 C。

## 本轮只支持静态模式

```yaml
pct_mapping_mode: static
pct_surface_noise_tolerance: 0.05  # 米，同一表面的匹配容差
pct_maturity_min_points: 3        # 达到这个点数即成熟
```

每个点按输入顺序进入自己的 XY 列，只有加入后整组最高、最低实测高度之差不超过容差，
才允许进入该组。在这些候选中选均值最近的组，距离相同时按编号确定。
默认 5 cm 限制整组跨度，不能依靠均值移动串接跨度更大的高低台阶回波。
未成熟组用 `H_n = H_(n-1) + (z_n-H_(n-1))/n` 更新，达到 num 即成熟。
允许同帧或多帧累计。`num=3` 时第二、第三个点各更新一次表面高度。
同一新点被多个切片引用时，表面计数仍只增加一。

成熟组的带内重复点保持原高度，仅记录已接纳高度的上下界，供后续跨度检查；
普通平面只改变这两个界限不会触发层格重建；模糊/竖直回波上界若改变，仍检查已有的近地噪声过滤。
带外点建立新候选，独立计数，并触发相关 G/C 重新评估。
新表面从首个有效点起参与各切片的 G/C 选择和代价计算。
若其高度超过旧 G 加匹配容差，并且是该切片以下最高的表面，本批地图提交时即成为 G。
同一表面在更低的切片上也可以成为 C。未成熟表面的组内高度随点云继续更新。
新点只更新一个物理高度组，再通知所有相关层格，不分别对每层重复求均值。

两个组只有合并后的实测高度总跨度仍在容差内才统一记录：已有成熟组优先，两个成熟组保留较早成熟值；
均未成熟时按原输入序号合并最早 num 个真实样本，使用点数加权均值。
统一记录后各层更新引用，避免各自保存不同 G。无新点时，时间、发布和规划都不改变地图。
高低两组超出容差时各自保存、独立统计。高于两组的切片仅使用高组作为 G，低组不参与该 G 的均值；
两组之间的切片仍使用低组 G、高组 C，不删除其他切片需要的真实高度证据。
当前配置为 dynamic 会明确拒绝；不保留未启用的动态窗口和证据过期参数。

## 提交阈值与依赖更新

表面高度、成熟状态或引用编号变化后，收集对应层格，并统一调用局部地形、膨胀和版本更新流程。

高度匹配容差使用米，代价传播阈值使用代价值。G/C 缓存直接同步共享表面高度，
不再设置逐层高度死区，否则会破坏共享一致性。代价比较对象仍是上次传播值；
cost=20/50 等状态边界跨越强制传播。

每批输入：

1. 融合候选，收集正式基础变化。
2. G 变化更新本格/四邻格高差；C 变化更新本格净空。
3. 平缓标志变化再更新台阶窗口中的可站立计数；中间结果未变就停止对应分支。
4. 更新唯一的 relief_cost；terrain_cost 保持 passage_cost+relief_cost。
5. 地形代价达到传播阈值或跨状态边界后，更新其膨胀窗口目标格。
6. 去重后提交本次几何版本。

地形代价保存当前两项之和，另用传播参考值实现死区，避免破坏代价加法关系。
有明确低净空障碍但坡度不可评估时，起伏分量取 0，通行分量仍为障碍。
平缓/台阶计算沿用原生 PCT 的高差平方、`1.2*r*slope`、台阶高度及可站立比例分支。
两个窗口分别配置：地形窗口默认 7×7，膨胀窗口默认 13×13。

距离权重为 `clip(1-(d-robot_radius)/(safety_margin+resolution),0,1)`。
膨胀值是邻域内所有有效地形代价的加权最大值，包含自己。
障碍出现、消失和普通代价变化均可触发；不能只处理新代价>=50的源格。
对受影响目标格重新求最大值，允许降低，不拿旧膨胀值永久 max 累加。
膨胀结果不作为新的传播源。

代价膨胀与机体圆盘可行性分开：机体范围触及未知或真实障碍仍被普通规划阻挡。
圆盘与邻格 AABB 相交计算，任意实际位置也检查平移后的圆盘。
派生运算只处理受影响块及小型临时邻域，不做全图梯度、距离场或膨胀重算。

## 实测表面与未知区域

不执行平面拟合、射线补面或递推外推，不保存补面射线缓存及模型依赖。
未被真实点命中的区域保持缺失 G，不能仅因邻格存在地面就推算其高度。
后续真实观测到达时，按普通融合、成熟及局部代价更新流程处理。
PCT 的未知膨胀和机体空间检查保留；稀疏观测仍可能使规划失败。
实测 G 直接参加 PCT 净空、梯度、台阶及邻域可站立格判断。回波朝向仍用于分离地面、底面和立面观测及识别楼梯，通行代价独立于朝向标签。

## 规划、控制与执行

普通起终点和脱困退出使用同一 `point_safe_check`。
安全检查同时返回当前物理表面编号及其全部安全切片表示（`safe_layers`）。
A* 首先使用该检查选定的起终点锚点，不再独立按最高切片重新选层。
若该组合断连，则在同一物理表面、已通过相同安全检查的起终点切片组合内重试，
优先尝试同切片组合；不改换其他地面，不放宽安全条件。
普通规划和脱困 A* 共用这一锚点选择流程，各自保留原有准入策略。
规划诊断的后端数据 `anchor_search` 记录准入层、候选层、逐次搜索耗时/节点数及成功组合。
原生 PCT 的八邻域、搜索代价、层切换和 0.08 米 RDP 保留；在线接入的是分块读取。
有效零代价格允许通行，不再被当成未初始化数据。
保持地面高度与机体参考高度转换；普通及脱困 A* 不追加简化后验边或密集路径回退。

脱困 A* 借用同一地图、通过读取策略放宽起始膨胀重叠，不构造第二张地图。
独立直退保留扫掠冲突及净距检查。
控制模块选择目标和策略，路径处理模块统一下发并匹配 SCAN 回执。
委托目标通过普通安全点检查，不额外扩大停车圆，最终目标可携带 0.15 米 XY 容差。
exploration 不因新地图主动取消已下发路线，不发布速度或步态模式。

## 锁、新鲜度、发布

PCT 控制器的一次选点和规划共用一个读阶段；内部后端调用借用同线程已有读阶段，
避免递归获取非递归互斥锁。读阶段先设置规划标志，持写锁提交待更新证据，再切换为整段读锁。
读阶段内建图回调丢帧，交接期间也不允许写入；没有整图快照复制。
注册点云直接融合，不再等待补面专用的位姿配对队列。
地图线程与探索线程分开，地图回调分组可继续记录传感器活跃时间。
新鲜度依据传感器活跃及有效地图，不因稳定地图没有重算而超时。
输入版本、证据版本、几何版本、提交版本和待更新状态分别记录。

保留全量发布；表面输出缓存按几何版本复用。显示缓冲属于消息输出，不是规划地图。
`publish_map_topics` 默认开启；RViz、前沿及上升预览直接读取新图。
规划表面 PointCloud2 为 56 字节，原字段保留，另加
`passage_cost`、`relief_cost`、`terrain_cost`、`inflated_terrain_cost`。
flags bit0/1/2/3/4 为实体、未知、实体圆盘冲突、未知圆盘冲突、C 有观测；
bit5/6 为 G/C 成熟。slice_index 是相对最低世界切片的发布编号。
完整规划话题不省略重复切片，source=1（只发布实测表面）；统计层格数不是独立面积。
RViz 的 surfaces 显示话题将同一 XYZ 的共享地面只画一次，优先使用存在的安全切片表示；
planning_surfaces 保留所有切片和诊断字段，不改变规划地图。

## 验证

测试包含：三点等权均值与立即成熟、跨切片噪声只形成一个表面、多层共享编号/高度、
同点不重复计数、候选归并、成熟后带内忽略/带外新障碍、候选未成熟不接管 G/C、缺失 C 补齐、G/C 单调与无关层保持、
无新点不变图、扩图不搬迁块、容量原子拒绝、局部代价与完整依赖重算对照、
未知缺测不补面、双雷达真实点融合、原生 A* 及控制/执行反馈。
GPU 门槛仅在容差=0、num=1 时检查原始 G/C 极值一致性；默认均值表面有意不同于原生极值。
隔离 ROS 回执为模拟，不代表 Gazebo 或真机运动验收。
