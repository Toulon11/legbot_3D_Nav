# 三维局部选点优先与全局后备

## 范围和职责

控制器默认先查询以机器人当前支撑表面为中心的三维窗口。默认水平半宽复用 `local_search_radius: 10.0`，即 X/Y 各 ±10 米；`pct_local_height_above: 3.5`、`pct_local_height_below: 1.5` 分别控制向上和向下高度。在线适配器用当前起点检查识别的 G 作为中心高度；暂未找到表面时用机体高度减 `robot_reference_height`，普通起点检查随后仍会阻止不安全规划。

窗口按实际表面 G 过滤，不按切片编号推断楼层。前沿成员和实际观察位置都必须处于窗口内。上方楼梯/平台可以进入候选；不要求先清空同层。能否到达仍由原生 PCT 验证，窗口本身不保证跨层运动能力。

**窗口只限制目标选择，不裁剪累计规划图、不生成中途替代目标、不截断远距离路线。**一条完整路线执行结束后重新检查当前位置的局部窗口。

## 动态前沿和局部收益

局部查询通过已有空间索引找与窗口相交的簇，将其成员裁成窗口内前沿片。不会重新提取全图前沿，不会将局部片写成新的实测 G。

局部观察点由该片成员提出，保留成熟、无障碍和未知机体膨胀、代价0..20的位置。考虑离机器人的距离，优先留下较近候选；观察位置仍至少距机体同层0.50米。

局部 gain 为候选观察点附近2米、同高度相容前沿成员的潜在收益，取候选中的最大值，不再计入整个大簇的外部规模。这仍是潜在邻域收益，**没有完整雷达视场、遮挡可见性或实际新增信息量估计**。

控制器分数为：

```
frontier_gain_weight * log(1 + gain)
- path_cost_weight * 直线距离
- pct_direction_weight * (1 - cos(目标方向 - 当前朝向))
```

`pct_direction_weight` 默认0.5；0关闭方向项。距离仍是廉价直线近似，不宣称已经采用精确路径时间。log压缩收益，避免数百的整簇收益淹没几米距离差。

## 局部/全局切换

- 局部有有效候选：只从局部选择。
- 局部无有效新观察点或候选均处于已确认失败的冷却：报告 `pct_local_exhausted`，下一个控制回合查询全局。
- 局部候选搜索超时：暂挂并继续剩余局部候选，相关超时等待期间报告 `pct_local_search_pending`，不因超时直接标记局部完成或切全局。
- 轮次预算耗尽：报告 `pct_planning_yield`，释放地图，保留游标继续；不因预算耗尽切全局。
- 全局目标成功下发后，下一次重新选点又先查局部。路线执行中保持该目标。
- 起点不安全：原有脱困控制处理，不把它归类为“局部探索完”。

`frontier_cells` 仍保存全局未解决数量；`scoped_frontier_cells` 才是当前查询范围数量。局部为空不会令 `pct_region_complete`。局部/全局都没有新观察位置而仍有前沿时，报告未解决，保留证据。

## 完成记录修正

- 完成点的同表面相近视角排除半径 `pct_observation_revisit_radius` 默认1.0米，位于 `multi_layer_map.yaml`。这是观察点相似性策略，不是障碍膨胀或到达容差。
- 软地形代价变化会更新观察点评分，但不会单独清除完成记录。
- 完成记录对所有邻近簇生效；局部和全局查询均按相关空间位置过滤候选，防止换簇后重复下发相近位置。完成事件不使地图候选几何缓存全局失效。
- 旧前沿因真实观测成熟而消失属于探索进展，不因这种删除重新激活刚完成位置。
- 静态图普通边界扩展不会清除同一位置的完成记录。相关安全签名变化时复查该位置，实际不再安全或支撑高度实质变化才撤销；单个等价切片变化、附近位置变安全而该位置仍安全不撤销。上下层隔离、全局无关变化不撤销的规则保留。

这抑制相近视角重复，未实现完整的视角信息增益历史，因此不保证完全没有必要或无效回访；不能通过把未观测区域直接标成完成来避免回头。

## 诊断

- `/exploration/status.pct_selection_scope`：`local` / `global`。
- `pct_local_fallback_count`：持久累计的全局后备切换次数，便于避免漏读短暂状态。
- `pct_local_window`：水平半宽、上下高度与实际查询中心。
- `pct_scoped_frontier_cells`：本次范围的前沿规模。
- `/exploration/planning_goal.selection_scope`：该次目标从哪种范围选出。
- RViz前沿/观察点标记显示本次查询范围；地图显示仍为累计图。

## 验证

`test_pct_local_window.py` 验证窗口裁剪、上下层、局部空全局有候选、完成记录生命周期；隔离ROS测试 `exploration_pct_local_global` 验证局部空时使用原生全图规划全局目标，`exploration_pct_local_pending` 验证超时不转全局或派发部分路线。
