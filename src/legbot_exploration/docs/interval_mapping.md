# XY 列区间构图：当前在线主流程

`OnlinePct` 使用 `IntervalLayerMap`。`FixedLayerMap` 提供稀疏存储、增量提交和
固定切片回归参考；在线入口不再为每列按固定间隔建立一串导航格。

## 区间与节点

同列实测点按高度排序，相邻高度差不超过 `pct_column_continuity_threshold`
（默认 0.10 m）则合并为闭区间 `[a,b]`，单点也是区间。区间累计保存，无原始帧
列表。连续阈值、表面噪声容差和最小通行净空分别设置。原表面统计提供身份，
导航上下边界取实测区间端点。

相邻占据区间之间的开区间 `(b_i,a_(i+1))` 为候选高通空间。净空达到
`pct_min_clearance`（默认 0.50 m）且下边界已确认后，每列每区间只存储一个节点：

```
G = b_i; C = a_(i+1); node_z = (G+C)/2
```

净空不足的间隙不建立导航节点，但保留其表面及已知不可通行范围，不能作为
未知前沿。没有有限下边界的空间没有实测地面，不建立支撑节点。

有限上下端点只确定候选区间，不自动确认下端点为可用地面。新下边界必须有
**终点落在本 XY 格、从表面上方到达的实际回波命中**，同时有实测上方边界且
两者净空达到阈值，才能启用有限区间节点。有限区间不额外要求整根 XY 列的
垂直高度都被连续射线扫过，避免斜视台阶无法接续；没有实测 C 的开放区间才
要求连续自由射线证明净空下界。每条表面记录的
`support_hit_z` 只记录这种直接命中的高度，绑定表面身份和噪声范围；穿过本列
的其他射线、机身高度或新增 C 不能替代该命中。所有回波仍累计为占据表面，
不恢复按雷达高度统一划分 G/C 候选的机制。尚未取得直接支撑命中的上方回波
也不丢弃，后续从上方实际命中同一表面后可继续确认。
自由体素按高度有序二分查询，不跨缺测间隙。已经确认的同一实测表面可继续
复用；确认绑定本列表面身份及噪声范围，不能转移给其他高度的新表面。新增
上方 C 不会自动把此前未确认的楼板底面升级成 G。

未确认候选保留在 `pending_ground_intervals` 中，**不计算中点、不分配该候选的
导航工作格**，不进入已知区间共享、地形起伏、停车支撑或路径搜索，也不能
消除相邻真实地面的未知前沿。直接命中及净空证据补齐后，即使 G/C 数值没有
变化，也在同一次增量提交中启用节点并更新关联前沿及缓存。成熟高度均值冻结
不冻结这类新证据；重复静态命中则不重复重建。确认不会转移给同列的另一表面。

## 开放候选的证据

实际观测这一列时，机身参考高度不低于最上方占据区间顶端，才允许顶部开放
候选。该 G 同样必须有上述直接支撑命中或已有确认身份。一个或多个占据区间
采用同一规则。机身在区间下方看到孤立楼板，不会
直接在其上方生成地面节点；处于占据区间内部也不据此补图。

开放候选不等于无限净空。原生三维体素遍历记录“时间匹配的雷达原点到实测
回波”经过的自由体素，命中体素不清空。最多使用可靠量程（默认 5 m）以内的
实际射线，不把整个量程球标为自由。没有实测地面的 XY 仍未知。
超过可靠量程的真实回波不进入 G/C 表面组，但到这些回波的射线仍可提供量程内
的自由证据；不能把远回波整条射线一起丢弃。没有回波的方向不自动补成自由。

不要求实测上方 C，但必须有实测 G 和连续净空证据，两者缺一不可。未满足时
只保存待确认记录，不预先计算切片中点。从 G 向上连续的自由体素给出绝对
高度下界 `C_clear`。只允许贴地命中体素的一格
量化间隙，不跨越其他缺测间隙。净空达到阈值后才启用节点，共享范围另受
`pct_open_ceiling_share_height`（默认 G 以上 5 m）限制：

```
y = C_clear-G
node_z = G+y/2
C = NaN                     # 尚无实测天花板
未知实际上边界 >= C_clear   # 体素分辨率下的观测约束
```

规划查询以临时视图读取有效上界，不将下界写成实测 C。查询高度必须严格位于
`(G,C_clear)`。只有量程或机身位置、没有足够射线证据时，保留地面原始证据和
待确认候选，不能作为安全可通行空间。自由证据受体素分辨率限制，公共足迹、
起伏、机体净空和安全余量检查继续保留。

## 更新与连接

新点更新本列占据区间，重算相邻高通区间，处理节点增删、区间合并和分裂。
低于旧中点的新点也必须参与重算。只增加净空证据、G 没变也触发局部提交。
区间内的新点插入/合并占据表面并拆分高通区间，区间外的新点新增/扩展占据
区间；不会因已有 G/C 覆盖新回波就将其忽略。失效的旧共享范围同批撤销。

`node_z` 随 XY 列变化。为兼容前沿索引和稀疏 A*，使用严格高于 G 的首个高度桶
作存储地址，地址间隔不大于最小净空的一半，保证恰好达到净空阈值的区间也有
内部查询位置；地址不是节点高度。调度可创建不分配
工作格的逻辑查询平面，同列 G/C 通过区间引用，不复制或补建邻格。

在线前沿的已知判定统一使用**当前主雷达实际高度 `z_q`**，平层和跨层相同。
主雷达固定为 `cloud_topic` 对应输入，使用与已接收点云时间戳匹配的
`cloud_sensor_odom_topic` 原点 Z；辅助雷达只融合证据，不改变查询高度。
这个高度不取整到高度桶，也不是 `node_z`、G 或机身高度。

本列已有已确认区间且 `G < z_q < C_eff` 时直接引用真实节点；其中有限区间
`C_eff=C`，开放区间 `C_eff=C_clear`。明确占据区间覆盖 `z_q` 时为已知障碍。
两者都未命中则在本轮查询下保持未知，不以另一高度的节点或仅同 G 的记录
兜底判为已知。历史物理节点仍保留，供其有效区间内的停车及路径规划使用。

各逻辑切片引用上述同一高度的共享查询及前沿拓扑，不各自重建一套簇。在已知非障碍格八邻域生成前沿；未知格
的八邻域存在已知障碍时不生成前沿。同 G 辅助高差筛选仍保留，辅助估计不写入
实测 G。新证据及查询高度变化同批更新涉及的前沿、选点缓存和显示；一次只
调度一个切片的簇，物理任务历史继续共享。

各列的有效上下边界及障碍端点建立有序事件索引。雷达高度变化时，只更新跨过
端点的列及其前沿邻域；没有端点跨越时不重建簇。新增切片只增加引用，共享视图
按变化列增量更新。状态输出 `shared_frontier_topologies=1`、`frontier_cut_references`、`frontier_query_height`、
`frontier_height_changed_columns`，每路输入另标识 `frontier_query_reference`。

同列其他高通区间以边界、实测来源及成熟状态匹配。未变化的节点对象直接复用，
只更新变化区间覆盖的虚拟查询高度及相关足迹邻域的规划版本。不使用整列或
整个高度范围的版本去废弃另一房间的路线与停车缓存。

融合和地图提交在地图执行器的写阶段完成。探索读取已提交版本，采用非阻塞
读租约；写阶段占用地图时，探索报告 `waiting_for_map_update` 并让出控制回调，
位姿与动作回执继续接收，不在读阶段调用建图。观测结束的账本提交可短暂等待
地图，但所属转向先取消，迟到回执不能阻塞后续任务。
读取遇到写锁时保留快速重试状态；写入完成后给等待的读取让出 0.25 s 窗口。
点云融合及发布回调在获得写锁后再次检查此窗口，避免已排队回调抢占它。

普通观测点的 2 m 目标半径扣除最终停车容差和半格对角线余量。距离筛选在方向
代表选取前执行，并且只把保留余量后可见的成员送入后续视野检查。扫描过程中
由地图提交缓存目标解决状态，目标已解决时提前结束；收益按唯一 XY/地面高度
计数，不按切片引用重复计数。

原生 A* 使用实际支撑 G 及有效上界，运动边同时满足：

```
abs(G_next-G_current) <= step_max
min(C_effective_next,C_effective_current)-max(G_next,G_current) >= minimum_clearance
```

中点不同不会断连，高差合格也不能越过低净空。路线仍执行公共安全验收。
原生搜索把查询别名归到物理节点的存储地址，多个切面引用同一地面时只分配和
扩展一个搜索节点，不再逐切面扫描同一 XY 的重复状态。
足迹按参考 G 在同列有序区间中寻找实际支撑，不因兼容切面处于立面内部就忽略
上方踏面。障碍膨胀仅在同列已有净空合格、地形合格且高差不超过单步上限的
实测踏面时排除其下方立面；真实墙体仍然阻挡。实际行走边的 16 cm 上限不变。

外围雷达盲区检查直接读取已知 G/C 区间。即使某块已观测地面不能从停车点按
16 cm 步高连通，也不能因此重新标为“缺测”；真正停车足迹及行走路线仍执行
原来的支撑、净空和高差约束。上行切面一轮失败后保留具体缺测点交给补扫，
同一位置的小幅代价更新不会自动重开整轮失败候选。

补扫验收区分 `observed_count`（收到回波）和 `resolved_count`（导航缺项已解决）。
只有对应高度获得已启用的实测支撑区间、确认已知障碍或目标表面被实际否定，
才结算该目标；`gain` 统计解决数。原始高度匹配而节点仍缺测时，保留目标，
输出 `missing_support_hit` / `missing_continuous_clearance` 等具体缺项，允许在
原有视角、移动及区域预算内更换有效观测位置。同一无效视角不重复尝试。
不因扫描动作完成或扫到同列其他高度的点就永久屏蔽目标，也不把无关新高度
一并标记为已完成。只增加自由证据而激活已有实测 G，也可触发解决和重规划。
已知上行支撑是纯导航目标，仅执行路线及包含到点误差的完整停车足迹检查，
不额外要求站在这里观测外围盲区。真正的前沿观测站位仍执行完整视野检查。

## ROS 与验证

`surfaces`、`planning_surfaces` 点记录改为 64 字节，原字段偏移不变，追加
`node_z`（56）及 `C_clear`（60）。`z` 仍为 G，`ceiling_z` 为实测 C，开放节点为
NaN；`clearance` 可表示净空下界，flags 的实测 C 位不因下界存在而置位。
`slice_index` 是兼容查询索引。

状态新增 `mapping_mechanism=xy_passage_intervals`、`interval_nodes`、
`pending_open_intervals`、`pending_ground_intervals`、`free_evidence_columns`、`node_height_kind`。
无雷达原点的调用保留已有的离线预标注表面导入语义：本次实际导入的表面可
作为有限区间的已确认支撑，不会顺带确认同列其他历史表面。线上双雷达入口
始终提供时间匹配的原点，执行实际射线准入。离线导图可显式设可靠量程为 0，
不伪造开放净空。

回归：`ctest --test-dir build/legbot_exploration -R exploration_interval_mapping`。
