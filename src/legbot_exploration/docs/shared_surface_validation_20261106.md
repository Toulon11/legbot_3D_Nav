# 共享静态表面落地与验证：2026-11-06

## 本次实现

- 同一 XY 列使用有序 SurfaceColumn，SurfaceRecord 保存编号、平均高度、计数、范围及成熟状态。
- 新点只更新一个真实高度组；均值为 H += (z-H)/n。默认 num=3，成熟后忽略阈值内点。
- 阈值外的新高度仍被接受，形成新候选，独立计数；成熟地面不会阻止后来建立 C 或新楼层。
- 多个切片保存同一表面的编号及一致的 G/C 缓存；同一编号不会同时成为同格 G 和 C。
- 同列相近组统一记录：成熟者优先、较早成熟者优先；两个未成熟组按最早 num 个唯一输入样本求均值。
- 使用有序索引二分定位 G/C，跳过无关高度；每帧去重提交受影响层格，再执行现有局部地形与膨胀更新。
- 只支持 static。删除动态窗口/过期、逐层独立冻结、三维均值/散布矩阵/协方差、极值尾部统计。
- PCT 不保存射线、补面模型或推断表面；二维占据图自己的射线空闲证据保留。

配置见 config/multi_layer_map.yaml：

```yaml
pct_mapping_mode: static
pct_surface_noise_tolerance: 0.02
pct_maturity_min_points: 3
pct_max_surface_records: 2000000
```

旧 pct_maturity_height_span、pct_dynamic_*、pct_g_update_threshold / pct_c_update_threshold、
z_resolution、pct_max_height_bins 已删除。容量现在按共享表面记录计数，状态输出
pct_surface_records / pct_map.surface_records。读写锁、可选全量发布和下视雷达默认开启保持现有接口。

## 构建与测试

构建 legbot_exploration 成功，完整 15 项 CTest 通过（约40秒）。
其中21个静态地图测试包含：三点等权均值、同帧达到num立即停止计数、跨切片噪声、
多层共享编号、唯一点计数、候选归并、成熟后新障碍、后补C、G/C单调、未知不补面、
局部代价与完整依赖重算、扩图不搬迁、容量超限原子拒绝等。
其余门槛覆盖C++嵌入、原生A*、GPU原始极值对照、双雷达输入、控制、脱困及执行反馈。
GPU对照仅在容差=0、num=1时保持原生极值基准；默认均值结果有意不同于原始极值。
