# 按 XY 列的实测开区间构图

每列累计保存真实回波，按高度排序。室内仅保留实测区间 `G < x < C` 中的固定高度切片；
切片间隔仍为 `slice_height`，默认 0.5 m。G/C 端点不属于区间，既不额外添加最高、最低
边界切片，也不因有一个 G 就强保留区间外的首张切片。没有固定切片落入的窄区间仍保留
原始表面证据，但不创建没有上下实测依据的工作格。

## 所有实测回波参与 G/C

G/C 是切片相对实测回波的上下界角色，不是点云预分类。每帧只融合本列实际命中的点，
不以雷达高度、法向、上表面/底面或模糊分类限制其资格。同列使用有序的高度组：
切片下方最近的实测组为 G，上方最近的实测组为 C。表面噪声归组、成熟均值冻结、
实测来源 ID 和补扫任务自己的 last_seen 保留。切片端点仍不属于有限开区间。
两个雷达继续使用时间匹配的原点进行量程过滤和实际补扫射线验收。

## 开放空间例外与 5 米共享上限

默认 `pct_allow_open_ceiling: true`。本列最高实测组没有上方回波时，建立一张严格高于
它的工作切片，C=+inf。查询其他切片时同样引用该组，但限制为 `G < 切片高度 <= G+5 m`；
参数 `pct_open_ceiling_share_height` 默认 5.0 m。该范围是共享上限，不表示上方空间已被
完整扫描，实际停车/路线仍检查净空、起伏、占据、足迹及单步能力。严格模式 false 不建
缺少 C 的工作格。共享不分配或填充邻格。

收到新上方回波后，下方 G/C 改为有限区间，旧开放引用按相关高度失效；最高新回波仍可
建立自己的开放切片。这是按实际高度排序的结果，不再根据回波分类排除它。

## 唯一的同列查询

`FixedLayerMap.observed_cell((k,x,y))` 查询切片高度，本格缺失或没有当前点云时也会查询
同 XY 其他已知工作格。有限区间严格覆盖；开放区间使用上述 5 米闭上界。
在适用记录中引用最大 G 和最小 C。
没有有效区间覆盖且不属于下述障碍区间时为未知，不能跨两个独立空间拼接上下界。通常直接借用原工作格；
确需组合不同上下界时只返回临时记录，并按更紧的净空检查代价，不创建实体邻格。
支撑、停车、盲区和 A* 共用这一查询。引用不会刷新回波时间或将旧数据伪装成新观测。

每列只在受影响时刷新去重后的区间索引。G 有序，使用二分定位，并用 C 前缀上界跳过
不可能覆盖的区间。构图按递增切片高度单向扫描已排序回波，避免每张切片重复扫描低层表面。
几何已知与通行安全分开：已知障碍也是已知，净空、起伏、膨胀、停车足迹和 A* 继续检查。

## 累计保存的不可通行障碍区间

每帧在同一个 XY 格内按高度排序回波，相邻高度差严格小于 `pct_min_clearance`（默认
0.50 m）就连接，逐点合并为闭区间 `[最低回波, 最高回波]`。间隔等于或大于净空长度
时保留为分段；仅用 1e-7 m 数值容差稳定 float32 临界比较，不新增连续性参数。
区间属于列的累计静态证据，重叠或间隔不足净空的新观测可以继续合并，不要求下一帧
再次扫到。孤立端点也保留，以便后续观测扩展。不同 XY 独立，G/C 和表面来源不被改写。
沿用已有 `surface_noise_tolerance` 归组：同一真实地面的噪声带不形成竖向障碍区间；
不同高度的连续实测跨度仍保留，不新增连续性参数。

查询高度落入障碍区间时，优先返回已知障碍，净空/地形/规划代价至少为 50；即使该列
没有 G、该切片格未分配或之后才创建切片，也不把它当未知前沿。有原 G/C 时仅返回
障碍视图；没有时返回 G/C 为 NaN 的障碍记录，不制造可站立的地面。停车和原生 A*
区分这种已知阻断与缺少观测，不再为它生成补扫缺测任务。机器人足迹及连通性使用相同
排除结果，区间变化按相关切片和足迹邻域使缓存失效。
已测到更高踏面、且满足原有跨越检查时，仍可使用其独立切片作为支撑；阻断的低切片
本身保持已知障碍，不通过切换切片把真实墙体放行。

这些是机器人不可穿过的区间，间隔内可能仍有雷达能穿过的小缝。视线查询继续使用
实际回波/实体证据，不把合并区间自动扩成实心光学墙。区间更新不创建实体邻格；查询
对列内有序区间使用二分，足迹排除使用切片/存储块的稀疏列索引，不遍历完整地图。

## 前沿成员及同 G 辅助高差检查

每张切片分别维护几何未知侧成员：同列有效区间查询没有适用记录，
八邻域至少有一个通过辅助检查的
已知非障碍来源 A，且八邻域没有已知实体障碍。同列已测得相同地面的工作格时，
即使开放上界只保留一张实际切片，也不再次生成该地面的前沿；超出有效共享区间的高度仍保持未知。
A 的同 G 层 S 只包含该 XY 引用同一实测地面身份的已知切片，
不能借用 A 在其他楼层表达另一地面的切片。有限区间和有界开放区间都支持查询引用。

对未知目标 B，仅查询 B 在 S 内的已知记录。低于当前切片的记录若 C 小于当前切片高度，
取其中最高 C 作为辅助高度；没有这类 C 时，取其他适用记录的最大 G。辅助高度与
A 的实测 G 相差不超过 `min(0.16, step_max)` 才保留该来源。S 内没有 B 的辅助证据时，
保留普通未知前沿。多个来源分别检查，再用留下的来源计算显示高度；所有来源均被排除
才移除该成员。辅助高度不写入 B 的 G，也不声明 B 可通行。

地形代价 `[0,20]` 的非实体障碍格可以作为来源。停车足迹因未知区域而被拒绝，不会取消
真实的探索边界；观测点与路线仍需通过完整安全检查。同列有效区间已覆盖的格，以及已知障碍格，
都不作为未知成员。相邻踏面 G 不同不能把已知格改为未知，不要求额外识别台阶边线。
开放区间仍遵守 G 上方 5 米的共享上限。具体补扫任务可以独立检查目标高度及新回波，
但它的目标匹配失败不能改写普通前沿的几何已知状态。16 cm 仅用于辅助跨越检查。每个切片/XY 最多一个成员，表面高度仅作为观测目标元数据。

点云变化先更新本列受影响区间及代价，再增量重查相关切片和八邻域、更新受影响簇。
辅助格 G/C 或来源的同 G 区间变化，即使当前高切片仍未知，也会触发对应边界重判。
`auxiliary_checked_sources` 和 `auxiliary_rejected_sources` 记录每批检查、排除的来源关系数。
不扫描完整地图找簇，不按到达楼层清图，不用楼层帧号使静态表面过期。
具体补扫任务仍保留自己的开始帧，判断目标地面是否真的收到新回波；普通前沿完成与
生成共用同列区间查询，不再凭孤立近高度回波提前结算未知工作格。

## 同 G 多切片择优

各切片独立保留簇 ID、成员与连通片。相同地面、重叠或八邻接的跨切片边界只登记为
备选关系，不合并成员，也不创建跨切片大簇。高度匹配沿用 5 cm 容差，重叠来源的
表面身份必须相容；不同踏面、独立地面和空间断开的区域分别调度。
生产选点只取当前有效主切片的簇；默认是第一张严格高于 h+0.16 m 的切片，超出脚下
地面的有效区间时才回退到有效切片。主切片内按覆盖收益及接近代价选点，并通过公共
观测与路径检查。所有切片继续独立维护成员，规划可以跨切片查询实际支撑。已观测和
失败记录仍绑定实际边界，新增切片不能重置已用预算，各切片 G/C 和规划代价保持独立。
备选关系只随受影响列和簇增量更新，查询不遍历完整地图重新聚簇。

新创建的主切片可仅维护逻辑前沿索引，通过已有列区间查询地面；不要求分配高切片工作格。
新切片索引从区间目录初始化一次，此后只处理变化列及其邻域。共享区间变化、代价变化
和相关新回波在同一建图提交中更新切片索引、簇及观测缓存；发布前再过滤已解决成员。
