# 导航卡顿修改与验证：2026-11-06

> 历史验证记录：下述补面优化及测试属于旧版本。当前版本已删除补面实现和相关测试，
> 不再生成推断表面；现有接口见 [在线 PCT](online_pct.md)。

## 修改范围

1. SCAN 的三维局部起终点距离小于 0.20 米时使用短多项式初始化，不再仅因距离短返回失败。
   保留单目标到达容差、楼层条件、B 样条优化、碰撞及动态可行性检查。
2. 射线补面中未变化的旧推断格不再重复整片扩展，同批 `(格, 模型)` 去重入队；
   新射线、障碍、支撑及证据撤销继续触发检查。显示按稀疏块批量生成并缓存消息，
   上升预览保留，实际规划不使用预览缓存。
3. 完整成功回执驱动下一路点立即下发，定时循环补充等待恢复情况。
   层析路线坐标、顺序、点数不变；未增加实时地图撤销路线的逻辑。
4. 控制模块对脱困目标复用普通安全检查，软性偏好可产生位移且更深入安全区的目标。
   两类地图使用各自的检查；不增加额外硬停车圆盘，不恢复历史点固定距离过滤。
   完成后等待新的已融合、已提交输入版本再复查普通起点，不要求成熟 G/C 改变。

地图仍是固定原点、稀疏分块、一个可变地图；规划直接持锁读取，不增加全图快照。
本轮未修改步态模式、RL 策略、执行协调器或 YAML 安全参数。
